记一笔 · 使用帮助

一本留在手机里的纸上账。下面是常见问题的答案。

记的账存在哪里？

默认只保存在这台设备上，不上传服务器，也不需要注册账号。换手机时可以「设置 → 导出备份」再导入；登录后也可以开启「云端与备份」，把整份账本备份到自己的账号。

扫图记账要 Key 吗？

不用。默认使用免费的 OCR 识别，选一张微信、支付宝、淘宝或美团账单截图、小票就能读。想让识别更准，可以在「设置 → AI 助手」里配置自己的 DeepSeek 或 Claude Key。

AI 助手收费吗？

默认的免费通道不需要 Key，偶尔可能需要排队。也可以在设置里切换到备用免费通道、本机模型或自己的 API Key。AI 回复仅供参考，入账前请核对金额。

要付费吗？

当前版本全部功能免费：多账本、CSV 明细导出、扫图记账、AI 助手都可以直接用。如果未来推出付费功能，会通过 App Store 内购提供，并提前在应用内说明。

怎么导入微信 / 支付宝账单？

微信：「我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单」；支付宝：「账单 → 开具交易流水证明」。把导出的 CSV 发到手机后，在「设置 → 导入微信/支付宝账单」里选择文件。

误删了数据怎么办？

本机数据删除后无法恢复，建议定期导出或云端备份。如果是刚删除的一笔记录，首页的提示条上可以点「撤销」。云端备份可以在「云端与备份 → 注销账号」里一次性删除。

能多设备同步吗？

可以。登录后进入「设置 → 云端与备份」，点「备份到现在」，在新设备用同一个邮箱登录后点「从云端恢复」。也可以不登录，用导出 / 导入备份手动迁移。

怎么登录？

目前支持邮箱 + 密码免费登录；已购买 Apple Developer 账号的正式版本还可以点「通过 Apple 继续」。手机号验证码和微信登录在当前版本没有开放。
